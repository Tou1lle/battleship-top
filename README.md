# ｡🇯‌🇸‌Battleship game PvE

A simple battleship game player vs computer. The computer here is really simple and every attack
is random, so its not intelligent. 
It's the final project for the Javascript course in The Odin Project - [instructions](https://www.theodinproject.com/lessons/node-path-javascript-battleship).

## 🎯Learning Goals

- Extensive training of core Javascript concepts
- Using a unit testing library
- Using Test Driven Development

## ⚙️Features

- Drag and Drop API
- PvE game

## 🛠️Tech Stack

- HTML
- CSS
- JS
- Webpack
- NPM

## 📝Notes

This project does not implement player vs player mode and the computer player is 
pretty dumb and simple. No scoreboard is tracked and reloading page resets the game.
